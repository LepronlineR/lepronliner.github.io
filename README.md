# Zhi Zheng Portfolio

A static portfolio and blog source project deployed to GitHub.

## Project Layout

```text
.
|-- .github/workflows/      # GitHub Pages deployment
|-- assets/                 # Images and 3D model assets
|-- content/
|   |-- blog/               # Blog post markdown
|   `-- projects/           # Project page markdown
|-- portfolio/              # Static interactive portfolio page
|-- resume/                 # Resume page and PDF
|-- scripts/                # Build scripts and browser JavaScript
|-- styles/                 # Site CSS
|-- public/                 # Generated site output (ignored by Git)
`-- index.html              # Home page source
```

## Run

```bash
npm run build
npm run serve
```

# Notes for me: 
`http://localhost:4173`

## Deployment

GitHub Actions builds the site and publishes the generated `public/` folder to the `gh-pages` branch.
In GitHub Pages settings, use `Deploy from a branch`, then select `gh-pages` and `/ (root)`.

Do not commit `public/`; it is generated by `npm run build` and ignored by Git.

## Writing Blog Posts

Add markdown files to `content/blog/` with front matter:

```md
---
title: My Post
date: 2026-05-22
description: A short summary.
tags: [math, games]
---

# My Post

Write markdown here.
```

## Writing Project Pages

Add or edit project markdown at `content/projects/<project-slug>/index.md`. The build creates the matching page in `public/projects/<project-slug>/`.
